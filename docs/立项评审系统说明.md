# ScoreSys 立项评审系统说明

> 当前版本说明已迁移至 [2026-09-01-盲评推荐与分轮规则说明.md](./2026-09-01-盲评推荐与分轮规则说明.md)。

本文件保留为稳定入口，后续系统规则、评委名单边界、盲评推荐算法、分轮资料清单和验收步骤均以同目录下的 2026-09-01 版本为准。

当前系统的关键数据边界：

- `project_pool` 是项目主档；`projects` 是项目在某场评审会中的 assignment。
- `meeting_reviewers` 是评审会评委快照，当前验收会使用已有数据库中的 7 名非管理员评委。
- 系统不在代码中注入 Nadia 或其他未在数据库快照中的评委。
- 评委结论是盲评输入，系统形成推荐结论；管理员确认后才可以形成手动覆盖。
- 评审完成度仍按原有评分分母计算，不能用盲评缺席情况改写完成度。
- 旧 scoring version 按记录读取；新建第二轮使用当前五维 100 分规则。
